# Night's Watch

Play the official v0.8.0 release: https://mononokej.github.io/NightsWatch-play/

This repository contains published web builds only. Development sources, original art, tools and design documents are maintained separately in a private repository.

The browser downloads the runtime JavaScript and assets to play the game; these files are publicly accessible. Public availability does not grant a general license to reuse the game or its art. Third-party font licensing is included at `assets/art/ui/fonts/noto-sans-sc/LICENSE`.

Development checkpoints from localhost do not automatically transfer to this site's browser storage. Do not clear or overwrite a local checkpoint to try to transfer it.
